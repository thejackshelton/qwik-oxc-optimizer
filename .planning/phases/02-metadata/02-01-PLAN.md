  <action>
Add three standalone functions to transform.rs (outside the impl block, as free functions since they don't need `&self`):

1. `binding_pattern_to_string(pattern: &BindingPattern<'_>) -> Option<String>` -- Recursive function converting OXC BindingPattern nodes to human-readable strings, matching SWC's `pat_to_string` exactly:
   - `BindingIdentifier` -> identifier name string
   - `ObjectPattern` -> `"{key1, key2: val, ...}"` format. For each `BindingProperty`: if `prop.shorthand` is true, push the key name only (SWC's Assign variant); if false, format as `"key: value"` with recursive call on value. **Skip rest element** in ObjectPattern (SWC skips `ObjectPatProp::Rest`). Handle property keys: `StaticIdentifier` -> name, `StringLiteral` -> value, `NumericLiteral` -> value.to_string(), `BigIntLiteral` -> raw string, computed -> `continue`/skip.
   - `ArrayPattern` -> `"[elem1, elem2, ...]"` format. For `None` elements, push empty string `""` (produces `", "` gaps matching SWC). For `Some` elements, recurse.
   - `AssignmentPattern` -> recurse on `.left` (use the LHS, ignore the default value)
   - Return `None` for empty object/array patterns (SWC returns None when parts is empty)

2. `extract_param_names_from_params(params: &FormalParameters<'_>) -> Vec<String>` -- Iterate `params.items`, call `binding_pattern_to_string` on each `param.pattern`, collect `Some` results. Then handle `params.rest`: if present, call `binding_pattern_to_string` on `rest.argument` and prepend `"..."` to the result. Return the collected names vec.

3. `extract_param_names_from_argument(arg: &Argument<'_>) -> Vec<String>` -- Match on the argument:
   - `Argument::ArrowFunctionExpression(arrow)` -> call `extract_param_names_from_params(&arrow.params)`
   - `Argument::FunctionExpression(func)` -> call `extract_param_names_from_params(&func.params)`
   - All other variants -> return empty vec

Then integrate into `record_segment`: Change the `param_names: vec![]` line (currently line ~629) to:
```rust
param_names: if let Some(first_arg) = call.arguments.first() {
    extract_param_names_from_argument(first_arg)
} else {
    vec![]
},
```

The existing props destructuring override at line ~1660 (`seg.param_names = vec![info.raw_props_name.clone()]`) MUST remain unchanged -- it correctly overwrites param_names for component$ with destructured props.

Important OXC AST details:
- `FormalParameters.rest` is `Option<Box<BindingRestElement>>` where `BindingRestElement` has field `argument: BindingPattern`
- `BindingProperty` has fields: `key: PropertyKey`, `value: BindingPattern`, `shorthand: bool`
- `ObjectPattern` has `properties: Vec<BindingProperty>` and `rest: Option<Box<BindingRestElement>>` (the rest in ObjectPattern should be SKIPPED per SWC behavior)
- `ArrayPattern` has `elements: Vec<Option<BindingPattern>>`
