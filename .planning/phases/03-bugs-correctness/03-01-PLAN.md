  <name>Task 1: Preserve extra arguments in named $-suffixed calls (BUG-02)</name>
  <files>crates/qwik-optimizer-oxc/src/transform.rs</files>
  <action>
In `exit_expression`, find the `DollarCallKind::Named(name)` match arm (around line 1844-1873). Currently it creates `args` with capacity 1 and only pushes the QRL replacement. Fix it to pass through ALL extra arguments from the original call:

1. Change `ctx.ast.vec_with_capacity(1)` to `ctx.ast.vec_with_capacity(call.arguments.len().max(1))`
2. After `args.push(Argument::from(replacement))`, add a loop:
   ```rust
   // Pass through additional arguments (e.g., { tagName: "my-foo" } for component$)
   for i in 1..call.arguments.len() {
       let placeholder = Argument::from(ctx.ast.expression_identifier(SPAN, "undefined"));
       let extra_arg = std::mem::replace(&mut call.arguments[i], placeholder);
       args.push(extra_arg);
   }
   ```
3. This applies to ALL named $-suffixed calls, not just component$. SWC passes through all extra args for all marker functions.

IMPORTANT: The `call` variable is the ORIGINAL call expression (e.g., `component$(fn, opts)`). The `replacement` is the QRL expression that replaces the first arg. The extra args (index 1+) must be moved from the original call to the new call.
  </action>

<task type="auto">
  <name>Task 2: Add source text to segment body codegen for comment preservation (BUG-06)</name>
  <files>crates/qwik-optimizer-oxc/src/transform.rs</files>
  <action>
In the segment body serialization code (around line 1796), the current code is:
```rust
let mut codegen = oxc::codegen::Codegen::new();
codegen.print_expression(expr_val);
```

Change it to pass the original source text so OXC codegen can emit comments:
```rust
let mut codegen = oxc::codegen::Codegen::new()
    .with_source_text(&self.source_code);
codegen.print_expression(expr_val);
```

The `self.source_code` field already exists on QwikTransform (it's `&input.code` passed in the constructor). OXC codegen reads comments from the source text by span position. Without source text, comments are silently dropped.

NOTE: This preserves comments whose spans fall within the serialized expression's span range. For synthetic AST nodes (SPAN), no comments will be found, which is correct behavior.
  </action>
  <verify>
Run `cargo test --package qwik-optimizer-oxc 2>&1 | tail -20` to confirm compilation and test execution. Check comment-related snapshot diffs:
`cargo insta test --package qwik-optimizer-oxc -- example_use_watch 2>&1 | head -30`
  </verify>
  <done>Segment module code includes source comments that were present in the original input. Comments like "// Double count watch" appear in extracted segment output.</done>
