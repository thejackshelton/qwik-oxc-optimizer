  Return `(result_expr, count, any_child_mutable)`.

  **CRITICAL NUANCE:** The mutability check for children expressions in `ExpressionContainer` must happen BEFORE signal wrapping transforms the expression. The current code checks for signal wrapping first and continues. The `other` variable at line 1760 is the expression AFTER wrapping attempts. If an expression WAS wrapped by `_wrapProp` or `_fnSignal`, it became a CallExpression to one of those functions -- which should be treated as IMMUTABLE.

  So the check is: after all wrapping attempts, if the final expression is:
  - A `_wrapProp(...)` call -> immutable (const)
  - A `_fnSignal(...)` call -> immutable (const)
  - A `_jsxSorted(...)` call (nested JSX) -> tracked via jsx_mutable save/restore
  - A string/number/boolean literal -> immutable
  - An identifier that's an import -> immutable
  - An identifier that's NOT an import -> MUTABLE (e.g., `globalThing`, local variable)
  - Any other call expression -> MUTABLE
  - Template literal -> check if it has expressions (with = mutable, without = immutable)

  Rewrite the mutability check to happen AFTER the signal wrapping `continue` branches, right before `child_exprs.push(other)` at the end:
  ```rust
  // After all wrapping attempts, check remaining expression mutability
  if !is_child_expression_immutable(&other) {
      any_child_mutable = true;

  child_exprs.push(other);
  ```

  **3. Create helper function `is_child_expression_immutable`:**

  ```rust
  /// Check if a child expression is immutable for JSX flag computation.
  /// Mirrors SWC's convert_to_signal_item is_const check + convert_children call check.
  fn is_child_expression_immutable(expr: &Expression<'_>) -> bool {
      match expr {
          // Literals are always immutable
          Expression::StringLiteral(_)
          | Expression::NumericLiteral(_)
          | Expression::BooleanLiteral(_)
          | Expression::NullLiteral(_) => true,

          // Known immutable function calls
          Expression::CallExpression(call) => {
              if let Expression::Identifier(ref callee) = call.callee {
                  matches!(callee.name.as_str(),
                      "_wrapProp" | "_fnSignal" | "_jsxSorted" | "_jsxSplit" | "_jsxC"
                      | "_IMMUTABLE"
                  )
              } else {
                  false
              }
          }

          // Fallthrough: handles TemplateLiteral (with/without expressions),
          // identifiers, member expressions, etc. via is_const_expression
          other => crate::is_const::is_const_expression(other),
      }
  }
  ```
