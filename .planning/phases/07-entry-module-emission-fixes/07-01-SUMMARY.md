## Decisions Made

- Included fallback path that injects hoisted stmt if variable name extraction fails (defensive coding)
- Removed `|| !hoisted_stmts.is_empty()` proxy from _fnSignal import check -- the proxy was over-broad (any hoisted stmts existing globally doesn't mean this segment uses _fnSignal)
