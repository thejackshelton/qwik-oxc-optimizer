<objective>
Implement scope-aware identifier classification for JSX prop and children immutability flags.

Purpose: Fix 34 of 59 JSX flag mismatches by replacing blanket identifier assumptions with const-binding-aware checks. Currently `is_const_expression` treats ALL identifiers as non-const (props go to var_props incorrectly) and `is_child_expression_immutable` treats ALL identifiers as immutable (children marked immutable when they shouldn't be). SWC uses `ConstCollector` scope analysis for both -- we approximate with a `const_bindings: HashSet<String>`.

Output: Updated flag computation that correctly classifies identifiers based on whether they are imports, const bindings, or mutable bindings. Fixes 21 SWC=3/OXC=1 mismatches (identifier props) and 13 SWC=1/OXC=3 mismatches (identifier children).
</objective>

```rust
pub(crate) fn is_const_expression_with_scope(
    expr: &Expression<'_>,
    const_bindings: &std::collections::HashSet<String>,
) -> bool {
    match expr {
        Expression::Identifier(ident) => const_bindings.contains(ident.name.as_str()),
        Expression::StaticMemberExpression(member) => {
            // X.prop is const if X is a const binding (import or const declaration)
            if let Expression::Identifier(obj) = &member.object {
                const_bindings.contains(obj.name.as_str())
            } else {
                false
            }
        }
        // For all other cases, delegate to the existing is_const_expression
        _ => is_const_expression(expr),
    }
}
```
