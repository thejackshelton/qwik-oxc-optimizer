  <files>

  <action>
For `EntryStrategy::Hoist`, SWC extracts the first argument of each `inlinedQrl()` call into a preceding named const declaration, using the segment name as the variable name:

```js
// SWC Hoist output:
const AppDynamic1_component_R00UJ05gbes = (props) => { ... };  // Extracted
export const AppDynamic1 = componentQrl(inlinedQrl(
  AppDynamic1_component_R00UJ05gbes,  // Reference to extracted const
  "AppDynamic1_component_R00UJ05gbes"
));
```

OXC currently keeps the callback inline:
```js
// OXC Hoist output (wrong):
export const AppDynamic1 = componentQrl(inlinedQrl(
  (props) => { ... },  // Inline, not extracted
  "AppDynamic1_component_R00UJ05gbes"
));
```

**Implementation in exit_program:**
1. After all traversal is complete and `inlinedQrl()` calls have been built
2. If `EntryStrategy::Hoist`:
   - For each `inlinedQrl(callback, "name", ...)` call in the output
   - Extract `callback` (first argument) into `const name = callback;`
   - Replace the first argument with an identifier reference to `name`
   - Insert the const declaration BEFORE the statement containing the inlinedQrl call
3. This is done in SWC's `fold_module` at lines 2567-2592

The segments to extract are tracked in `self.segments` — iterate them in source order, build const declarations from each segment's expression, and insert them before the module item that contains the reference.

**Affected tests:** All tests using Hoist strategy (check `entry_strategy: Hoist` in test.rs — likely ~11 files including `example_inlined_entry_strategy`).

Note: This ONLY applies to Hoist strategy, not Inline. Check the entry_strategy for each test case.
  </action>

Run `cargo insta test -p qwik-optimizer-oxc` and check:
1. `example_inlined_entry_strategy` shows extracted named const before inlinedQrl reference
2. Other Hoist-strategy tests show the same pattern
  </verify>
  <done>
- Hoist strategy extracts segment callback to named const declaration
- Named const uses segment name as variable name
- Reference in inlinedQrl points to the named const
  </done>
