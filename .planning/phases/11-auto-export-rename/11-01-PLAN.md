<objective>
Implement the `_auto_` prefix mechanism for segment import re-exports, matching SWC's behavior across 8 affected test cases.

Purpose: When segment bodies reference module-level declarations that are NOT user-exported, SWC re-exports them with `_auto_` prefix in the entry module and imports them with alias in segment files. This is the last major structural diff category before Phase 12 cleanup.

Output: Entry modules emit `export { X as _auto_X }` at bottom; segment files use `import { _auto_X as X }` for self-imports; `self_import_source()` respects `explicit_extensions`.
</objective>
