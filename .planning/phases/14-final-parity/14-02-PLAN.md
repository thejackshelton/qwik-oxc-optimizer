**SWC behavior (correct):** For single-spread `_jsxSplit`:

- BUT earlier code around line 2625-2648 may be putting explicit const_props into the var_props object incorrectly

The fix: In single-spread mode:
1. Only put var_props (non-const) props into the var_props object alongside `_getVarProps(source)`
2. Do NOT put const_props items into the var_props object
3. Pass `_getConstProps(source)` as the separate 3rd argument

Examine the `all_before` and `all_after` construction (around lines 2580-2600). Currently it interleaves const_props into the var_props object:

The fix for single-spread should be:

- `all_after` = only var_props items after spread position

Add `_createElement` support for simple spread-only JSX elements.

**When to use _createElement (SWC pattern):**
- Element has ONE spread attribute
- Element has NO explicit props other than `key`
- Effectively: `<tag {...source} key={k} />` or `<tag {...source} />`

**_createElement call signature:** `_createElement(tag, { ...source, key })` or `_createElement(tag, { ...source })` -- all spread source props go into a single object, with optional key mixed in.

**Implementation:**

1. At the top of the spread handling section (around line 2543 `if has_spread {`), add detection for the simple spread pattern:
   ```rust
   let is_simple_spread = has_spread
       && spread_args.len() == 0  // only one spread (first was removed)
       && var_props.is_empty()    // no explicit var props (events go here)
       && const_props.is_empty(); // no explicit const props
   ```
   Note: `key` is handled separately (not in var_props/const_props), so checking those empty is correct.

2. If `is_simple_spread`, build `_createElement(tag, { ...source })` or `_createElement(tag, { ...source, key })`:
   ```rust
   if is_simple_spread {
       // Import _createElement
       self.import_tracker.needs_create_element = true;

       // Build props object: { ...source } or { ...source, key }
       let mut obj_props = ctx.ast.vec();
       obj_props.push(ctx.ast.object_property_kind_spread_property(SPAN, spread_source));
       if let Some(key_expr) = key_value {
           // Add key: <expr> property
           let key_prop = ctx.ast.object_property_kind_object_property(
               SPAN, PropertyKind::Init,
               ctx.ast.property_key_identifier_name(SPAN, "key"),
               key_expr, false, false, false,
           );
           obj_props.push(key_prop);
       }
       let props_obj = ctx.ast.expression_object(SPAN, obj_props, None);

       // Build _createElement(tag, props_obj)
       let callee = ctx.ast.expression_identifier(SPAN, "_createElement");
       let mut args = ctx.ast.vec();
       args.push(ctx.ast.argument_expression(tag_expr));
       args.push(ctx.ast.argument_expression(props_obj));
       return ctx.ast.expression_call(SPAN, callee, NONE, args, false);
   }
   ```

3. Add `needs_create_element: bool` to `ImportTracker` struct in transform.rs (initialize as false).

4. In the import emission code (transform.rs exit_program Phase 3), add:
   ```rust
   if self.import_tracker.needs_create_element {
       let stmt = import_rewrite::build_aliased_import("createElement", "_createElement", core_module, ctx);
       synthetic_imports.push(("_createElement", stmt));
   }
   ```
   Place this AFTER the _jsxSplit import block (since _createElement is a related JSX utility).
