## Cross-Phase Integration Issues

### GAP-1 (Critical): `_hf*` declarations leaking into entry module

**From:** Phase 4 (_fnSignal transform) → **To:** Phase 6 (entry module emission)
**Issue:** `hoisted_function_stmts` injected into entry module unconditionally in `lib.rs` lines 169-199. Phase 6's `collect_referenced_idents()` filtering doesn't cover these.
**Impact:** ~50 tests, 172 added `_hf*` lines. Largest single diff category.
**Fix:** Filter `hoisted_stmts` from entry module when body doesn't reference `_hf0` identifiers.

### GAP-2 (Significant): Entry module lazy import sort key incorrect

**From:** Phase 6 (import ordering) → **To:** Final output
**Issue:** `sort_by(|a, b| a.0.cmp(&b.0))` sorts by hash identifier, but SWC uses `BTreeMap<Id>` with different key semantics.
**Impact:** ~80 tests with multiple lazy imports in wrong order.

### GAP-3 (Significant): Identifier scope analysis missing

**Within:** Phase 5 (JSX flags)
**Issue:** `Expression::Identifier(_) => true` in `is_child_expression_immutable()` treats all identifiers as const. SWC uses scope analysis.
**Impact:** 45 flag mismatches (OXC=1/SWC=3).

### GAP-4: `_rawProps` override restricted to `component$`

**Within:** Phase 2/4 boundary
**Issue:** `is_component_exit` guard excludes `useResource$` and other hooks.
**Impact:** 1 paramNames mismatch.

### GAP-5: Logical `&&` key generation and flag propagation

**Within:** Phase 5 (JSX)
**Issue:** Native elements inside `prop.value && <div/>` get null keys; mutability not propagated correctly.
**Impact:** 28 key mismatches + 29 flag mismatches.

### GAP-6: q:p iteration variable injection incomplete

**Within:** Phase 4
**Issue:** 18 missing `q:p` entries despite infrastructure being built.
**Impact:** 18 lines of diff in ~10 tests.

### GAP-7: False-positive `_fnSignal` import in segment files

**From:** Phase 4 → **To:** Phase 6 (`code_move.rs`)
**Issue:** `if body_code.contains("_fnSignal") || !hoisted_stmts.is_empty()` adds import to all segments when any one uses _fnSignal.
**Impact:** 25 extra imports across snapshots.
**Fix:** Remove `|| !hoisted_stmts.is_empty()` check.

### GAP-8: `relative_paths` structural mismatch

**Within:** Phase 3/6
**Issue:** OXC uses `inlinedQrl` strategy for secondary `.mjs` file; SWC uses segment extraction.
**Impact:** 1 test, 215 diff lines.
